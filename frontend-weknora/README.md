# 知识工作台前端

独立的 React 前端，参考 WeKnora 的模型管理、知识库和对话布局，使用现有 FastAPI 接口。

## 启动

在本目录安装依赖（或复用兼容的现有依赖），然后执行 `npm run dev`，访问 <http://127.0.0.1:3001/>。开发服务器将 `/api` 与 `/static` 转发到 `http://127.0.0.1:8000`。`npm run build` 会先进行 TypeScript 检查再构建。

本机当前通过 `node_modules` 目录联接复用 `../frontend/node_modules`，迁移到其他机器时可运行 `npm install` 安装依赖。

首次使用请在“模型与设置”添加自己的模型。创建知识库需要选择向量模型；视觉模型按需配置。所选使用偏好保存在当前后端数据库，不会自动读取其他部署环境中的模型记录。

## 对话历史

会话列表保存在当前浏览器的本地存储中，刷新后可继续查看；它不会写入后端数据库，也不会在不同浏览器或设备之间同步。清除浏览器网站数据会删除本地会话。
