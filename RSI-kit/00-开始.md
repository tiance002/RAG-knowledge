# 天策接手 RAG-knowledge 的 RSI
2026-11-03 • Windows 本地交接 • 公开合成验收

## 第一次接手
1. 将整个 ZIP 解压到 D 盘，例如 D:\RSI-kit。打开并发送《01-天策任务.md》全文，给天策该目录的读取权限。
2. 已有 D:\RAG-R0 时，先核对工作区、提交和历史回执。原目录有未提交修改时，保持原状。新工作使用独立目录。
3. 新机器需 Git、Python 3、可读 GitHub 仓库或含固定提交的本地克隆。以下命令以解压目录为当前目录，目标目录须不存在。脚本安装固定版本的项目源码，保留完整祖先关系。默认通过 GitHub 下载，依赖复用本机已验证的 RAG Python 环境。

~~~powershell
py -3 install.py --dest 'D:\RAG-Dots-RSI'
~~~

若本地克隆已有 09a3146d，使用下面这条替代下载命令。已有目标目录可以单独用 --check 检查固定起点。安装失败会返回非零并保留现场，请核对输出，重试时选择新目录。
~~~powershell
py -3 install.py --source 'D:\RAG knowledge' --dest 'D:\RAG-Dots-RSI'
py -3 install.py --dest 'D:\RAG-Dots-RSI' --check
~~~

## 从公开夹具生成首次运行记录
优先复用已验证的本地记录。确实缺少时，再用以下命令。Python 和补充包目录均为原机示例，新机先确认实际路径、ABI 和依赖。缺依赖时报告具体模块与解释器，不要下载模型或重建生产索引。每轮预算与工程验证分别计数。
~~~powershell
Set-Location 'D:\RAG-Dots-RSI'
$py = 'D:\RAG knowledge\.venv\Scripts\python.exe'
$extra = 'E:\RAG quention\.venv\Lib\site-packages'
$env:RAG_TEST_EXTRA_SITE_PACKAGES = $extra
$origin = 'var/r1/dots-public-' + [guid]::NewGuid().ToString('N')
& $py scripts/run_rsi_offline.py --manifest experiments/r0/synthetic.json --out $origin
if ($LASTEXITCODE -ne 0) { throw 'R0 入口失败，请检查运行目录' }
~~~

确需重建等价子代演示时，在同一窗口执行下面的命令。此演示依赖上一条命令生成的 feedback.json，使用一个单独的工程配对，它不产生故障子代。移除程序只需停用新目录。该目录包含新的实验结果时先归档。
~~~powershell
& .\scripts\demo_rsi_inheritance.ps1 -Python $py -ExtraPackages $extra -OriginRun $origin
~~~
