# E2.1.1 扩展成员成本与 Tokenizer 核验

日期：2026-10-30。代码版本、语料范围与标签状态见成员质量报告。统计 **PASS（确定性字符/字节）**；可靠 Tokenizer **UNKNOWN**；D Token 预算执行 **BLOCKED**；第二阶段 B/C/D **NOT_RUN**。

- Context 正文字符/字节为最终去重成员正文的**逐项之和**，沿用 E2.0 口径，不含引用模板和成员间分隔符。另存 context_joined_chars/bytes，明确包含两个换行的拼接分隔符，不与旧统计混用。
- 完整 Provider 消息内容包括 System Prompt、用户问题、真实引用模板等所有已保存消息的 content；有历史消息时也应计入。本批为固定单轮请求。表中不是 Context Token，也不包含 JSON 角色/字段或传输封装。
- 账本另存 canonical JSON 序列化字节，只描述当前规范化表示，并非真实 HTTP 线上的全部字节。每个 Context/Provider Token 字段均 null + UNKNOWN，未用字符换算。
- 这些是固定 E2.0 A/B 的重新统计，未构建或执行 E2.1 C/D。

“真正新增”按不在**完整初始候选集合**中的成员统计，不能按是否是分组 seed 判断。X1 的初始 rank 2 Gold 虽成了邻块，仍是初始候选，不计为新检索收益。

初始候选已包含大量其他来源的相同表单字段；只减少邻块并不能移除全部这部分成本。若第二阶段要求所有初始种子保留，潜在压缩空间受这些已在初始候选中的成员约束。表内 IRRELEVANT 仍只是明确来源题的 AI 提议，不能宣称这些字符已经可安全删除。

60 次同 ID 关系重复没有造成 60 次最终重复发送；同正文不同 ID 则可能实际进入 Prompt，多来自跨文件模板。直接按正文合并可能破坏来源、时期和引用身份，不在本阶段实施。

X1 的新增邻块明显比 Word 长，且跨 Sheet；同源不等于同表、同指标。其表头、单位、年份已在直接证据成员内部，其他 Sheet 的辅助价值还未证实；在缺乏必要结构标签时不自动排除。Word 的项目身份标题位于不同成员，E2.0 已发现真实回答引用覆盖缺口，不能只保留数值行就宣称全部证据够用。

## Tokenizer 和模型映射

- ECS 数据库实际模型记录：默认 Chat 为 `XingChenAGI/Xing4.0-29B`；E2.0 获准对照显式使用 `zai-org/GLM-5.3-Flash`（已有配置角色为 VLM，但该实验确实是 Chat 请求）。本阶段两者均不调用，不改默认配置。
- 复用现有 ECS 环境：transformers 4.57.3、tokenizers 0.22.1、tiktoken 0.12.0，sentencepiece 未安装。库已安装不表示具有该模型的 Tokenizer。
- 检查 ECS 标准 Hugging Face、ModelScope 和项目模型缓存路径，未发现可用 Tokenizer 资产；本机标准 HF 缓存仅有无关语音模型。另保留本机库版本清单。该缓存检查有范围，不能证明服务器任意路径都没有资产。
- 额外在 ECS 将网络连接禁止，并设 HF_HUB_OFFLINE/TRANSFORMERS_OFFLINE，分别执行 `AutoTokenizer.from_pretrained(model_id, local_files_only=True, trust_remote_code=False)`。两个身份均返回 OSError / UNAVAILABLE；未下载模型、安装依赖或调用 API。
- **模型 ID → 精确 Tokenizer revision、Chat Template、特殊 Token 与供应商计数一致性仍 UNKNOWN。** 即使将来找到同名 tokenizer，仍需确认供应商模型版本/消息封装，不能直接当作真实请求用量。
- Context Token、完整请求 Token、本成员 Token 均 UNKNOWN；D 组固定 Token 预算执行 BLOCKED。当前只交付阻断依据，不以字符预算替代 D，不自行下载资产。

## 仅可复用的历史 usage

E2.0 的 3 个已返回响应合计 input 31,595、output 724，其中 reasoning 361；它们是当时完整请求的供应商 usage，**不是这六题每个成员的 Context Token**。Word 配对 B 比 A 输入增加 1,540（26.81%），单次配对没有质量提升证据；Excel A 为 UNKNOWN，不能补算配对 Token。

成功三次的价格乘 usage 估算约 0.0273032 元，原 UNKNOWN 用量/账单仍 UNKNOWN。本阶段新增外部 Chat/Embedding/Rerank/VLM/Judge 0 次；没有据此将历史 UNKNOWN 费用填 0，也不估算下一阶段实际账单。

## 分母、未验证项与审核后下一步

必要结构信息的完整人工单元清单缺失，不能计算必要结构保留率或“每新增必要结构单位的 Token 成本”；真实初始缺 Gold 恢复分母为 0，记 NOT_APPLICABLE。6 个直接 Gold 单元也不能与结构特征数相加充作效率分母。只统计字符减少不能证明信息效率提高。

下一阶段若获批准，先冻结结构必要性与 UNKNOWN 保守处理原则，再设计不依赖 Gold 的可解释 C 规则。建议优先审核**明确来源身份及同表/同指标结构关系**能否作为扩展成员选择依据；本阶段尚未实现或试跑。D 须先有获准、可信且固定版本的 Tokenizer 才能执行。Agent、真实模型质量提升和父块真实数据收益均不在本阶段通过范围内。

两份公开报告仅含汇总与方法；完整字段 JSON、Gold、原文特征片段、核验原始事件与路径仅保留在忽略提交且有 ACL 限制的本地目录。未经负责人批准不进入 E2.1.2。
