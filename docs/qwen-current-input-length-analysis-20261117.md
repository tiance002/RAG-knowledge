# 当前 Qwen 回答：按输入长度统计，而非比较平均长度

本轮仅使用每题当前最新保留的 Qwen 回答：296 题，257 完全正确、32 部分正确、7 错误，执行失败 0。另外 4 题原由 expensive 回答，不混入 Qwen 分母。GLM 重答及暂停前 38 份未评分输出也不改写 Qwen 标签。本报告不再分析已修复的历史空答或失败。

本批最大实际输入为 18,202 Token。分档结果没有呈现“输入越长，完全正确率越低”的单调关系；最高档反而有 41/44 完全正确。**这不证明长度没有影响，只说明本批数据不足以把长度单独作为强升级规则。** 各档题型、语言、证据质量和任务要求不同，不能把分档差异当成改变长度的因果效果。

供应商返回的模型名在 240 条记录中可确认是 Qwen；另外 56 条只保留了 Qwen 请求配置、没有返回型号字段。分组按既有 Qwen 请求归属，保留该证据限制。

| 600–999 | 5 | 1 | 3 | 1 | 20.00% |
| 1,000 及以上 | 2 | 0 | 2 | 0 | 0.00% |

长输出与不完全正确的关联更明显，但后两档样本只有 5 和 2 题，不能据此定通用阈值。复杂题本来可能需要更长回答；错误也可能使模型反复解释、先否认后纠正。因此不能断言“输出变长导致错误”，也不能把生成后才知道的输出长度放进生成前路由。

当前记录全部标为 COMPLETED。明确的 `generation_finish_reason=stop` 保留在 32 条中，其余 264 条没有该字段；原逐次输出上限也未全部保存，不能只凭输出长度绝对排除截断。本次不将未记录的结束原因推断为 length，也不修改既有对错判定。

## 从现有错因看上下文问题

本轮只检查已有判定和原始回答，不新增评分：

- **正确数值后增加错误说明**：结转结余、财政支出差额、公投及地方收入关系等题中，部分答案数值已正确，但补充的资金归因、集合关系或方向解释有误。
- **结论前后矛盾**：项目经理、应计负债、项目预算等题中，回答已经提到所需信息，又否认可以确定或给出冲突结论。仅降低输入总量不保证这种错误消失。
- **对象或字段归属错误**：不同项目成本混用、把支出说成收入，属于证据对齐问题，需要关注历史对象、同名字段和候选干扰。
- **必要条件遗漏或证据不在候选中**：操作流程、故障处置、角色归属等题缺少条件；部分所需段落没有进入最终候选。预算内的正文全部保留，也不等于所需证据已找到。

故当前更有依据的方向是区分独立事实读取、时序/数量/因果耦合、历史财务归属和条件机制，而非对所有长输入统一升级。

## 对路由优化的处理

已冻结 V4 为基线。V5 候选继续默认 Qwen、阈值 45，只调整任务之间的关系：

1. 普通独立的多事实读取基础分由 35 降为 25；涉及时间、量值或因果依赖时仍为 35。
2. 真实历史指代与财务字段同时出现，加 5 分。
3. 机制解释与 if/when/恢复/重试等条件同时出现，加 10 分。
4. 命令、配置键、接口路径、请求头等精确标识符读取，在没有运算或历史指代风险时再减 10 分。

上下文长度先**准确记录，默认权重为 0**。记录提供给路由器的消息序列的序列化字符数、系统文本、历史和问题长度；不是供应商 Token，也不等同于所有场景的最终完整载荷（显示偏好、工具 Schema 或供应商封装可能另计）。纯路由回放对 256 题重新组装当前预算下的完整参考消息，44 题读取已保存 GLM 输入；这份字符台账用于解释当前候选，不能替代上表的实际当前 Qwen 已保存用量。

分析中保留了一个“短简单字段降权／接近预算且强耦合加分”的长度实验版本，它只比无长度权重版本少升级 1 道 Qwen 正确题，没有新增已知可修正题覆盖。结合输入分档缺少单调关系，暂不把这点样本内收益固化成长度分数。

| 同一批 300 题纯路由指标 | 冻结 V4 基线 | V5 候选 |
| --- | ---: | ---: |
| GLM / Qwen | 97 / 203 | **88 / 212** |
| 已知 Qwen 不完整、GLM 正确题覆盖 | 21/26 | **23/26** |
| 全部已知 GLM 正确题遗漏 | 6/30 | **4/30** |
| Qwen 已答对但仍升级 | 69 | **59** |
| 两者都不完整但仍升级 | 4 | **3** |

V5 仍符合先前 60–100 道 GLM、最多遗漏 6 道已知 GLM 正确题的约束。本地和 ECS 隔离候选 300 条结果相同，网络及模型客户端被禁止，回答模型调用 0。V4 基线代码快照和决策未覆盖；相关回归 182 项通过，0 失败、0 跳过，7 条既有弃用警告。正式路由继续 OFF，生成任务仍暂停，未部署候选或重启正式服务。

这是已参与设计题集上的路由选择改善，不是新生成答案的正确率提升，也不是无偏泛化验证。V5 不读取历史对错标签、Gold、真实回答或实际输出长度来决定模型。
