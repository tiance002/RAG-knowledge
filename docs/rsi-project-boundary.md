# RSI 与知识库的项目边界

RSI 是面向知识库的独立实验与优化项目。知识库是被测系统，不等于 RSI 项目本身。当前代码以同一 Git 仓库中的 `rsik/`、RSI 脚本和报告托管；这不表示知识库业务服务与 RSI 共享运行状态，也不表示已经完成独立仓库拆分。

## 当前职责

| 项目 | 职责 |
| --- | --- |
| 知识库 | 业务查询改写、检索、知识入库、问答、数据库、索引、前端及服务流量 |
| RSI | 生成受限候选、隔离回放、事实与统计裁决、经验归档检索、费用记录及隔离影子演练 |
| RSI 的知识库适配层 | 读取固定版本的被测代码及评测输入，在隔离 Capsule 中执行，不修改正式知识库运行状态 |

S3 的“来源、版本和暴露记录”服务于 RSI 实验资格：明确评测材料的真实来源和版本、来源之间的依赖，以及材料是否已被开发、候选搜索或核查使用。知识库中存在、入库或检索过某文档，与 RSI 已经在开发或评测中使用该文档，是不同事件，不能直接互相替代。仅未发现 RSI 使用记录，也不能在记录不完整时判定材料未暴露。

## 三个不同概念

1. **业务查询改写**是知识库运行时功能，本轮不修改。
2. **query-aware selector** 是 RSI 已有的受限候选接缝，使上下文选择函数能够读取实际问题。它不负责重写问题，也不允许任意修改知识库系统源码。
3. **问题改述压力套件**是 RSI 离线评测数据：事先审定语义等价的问题变体，检查候选遇到不同问法时是否保留必要证据。它不是新运行时查询改写器。

前向与反向 seed 压力同样属于离线评测输入变化。变体要保留真实来源区间和必要事实，声明 seed 数量、可达方向及回退，不把重复变体计为新增独立来源。重新分段或构造重叠片段时使用新的版本化数据布局和血统，原 fixture、原结果及失败记录保留。

## 本轮执行边界

- RSI 工程和实验工件写入 RSI 工作区；知识库已有实验材料只读引用。
- 不修改知识库业务代码、查询改写功能、正式数据库、索引、配置、流量或服务。
- 不读取受限 FINAL/Gold 内容或绕过访问权限；合法可读的实验元数据不因文件名含 `restricted` 就自动等同于 Gold。
- 完整保留六个保护文件、事实门和统计阈值；工程修复不记为自主优化收益。
- 沿用原累计 USD 5 模型费用账本，不重置、不预留；模型或数据资格不满足时阻断依赖动作。
- 保留 Diagnosis、三个独立 Proposer、Curator、Meta；本轮没有授权任意系统源码自改或 S8。

独立仓库拆分、面向其他知识库的适配和生产接入不是本次离线证据补齐工作的交付声明。
