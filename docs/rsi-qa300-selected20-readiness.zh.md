# 用户筛选的冻结 300 题子集：RSI 接收与输入核验

本轮以用户提供的两份题号 CSV 为准，替代旧 RSI 候选资料的选题入口。原知识库 Gold、评分和 CSV 均只读，知识库正式测试分区不被改写；RSI 的 DEV/FINAL 是独立实验的派生用途。

## 已核对的清单与标签

| --- | ---: | ---: |

| 与正式 Gold、冻结 300 个运行输入匹配 | 20 | 20 |
| CORRECT | 10 | 16 |
| INCORRECT | 2 | 0 |

两组题号不重叠；正确性与引用标签逐题匹配原评分文件。PARTIAL 不改算成严格 INCORRECT。这些旧评分只用于预先选题和分层，不代表新 RSI 基线已通过或复现了旧回答。

原评分文件的严格正确率为 243/300（81%），PARTIAL 为 27/300，INCORRECT 为 5/300，空答或失败为 25/300。若只看有回答的 275 题，则正确率为 243/275；分母不能混用，也不外推为 500 题准确率。

DEV 的六类 CSV 标签实计为 2、5、3、6、8、9；最后的引用支持比交付说明中的 7 多 2，按 CSV 原值保留。这是标签计数核对，不等于已完成各类别必要事实及独立来源家族的验收。

## 已完成的被动输入工程

- 通过绑定的 v2 来源快照清单，解析到 DEV 31 份原始资料。136 次证据引用中，125 次具有显式 Gold 来源哈希匹配；11 次只具有快照清单哈希验证，仍保留 Gold 单条引用哈希未绑定的区别。
- 17 个 DEV 当前回答记录有检索捕获，共 239 条引用、217 个按请求计的上下文组。239 条捕获文本的内容哈希均匹配。
- 3 个 DEV 为历史/直接生成控制，没有当前检索结果；不伪造知识库成员，也不把 citation NONE 自动判成无效题。
- 14 个 standalone DEV 在新独立复测中采用空历史；这是新输入政策，不声称复制旧测评的完整历史上下文。
- 6 个语义多轮 DEV 使用实际用户输入和实际产生的助手回答构造固定前缀，不使用 Gold 的合成参考回答。失败的先前回合保持失败，不补造回答。
- 一个多轮案例保留其原始历史连续性 UNKNOWN 标志；其声明的直接依赖回合存在。实际前缀可定位不等于已经证明全部语义依赖充分，也不把上游不确定性归咎于候选选择器。
- 旧测评将一些单轮题放入连续会话，6 个 DEV 旧前缀含有 7 个本轮 FINAL 题号。这些旧前缀正文未被装入新的 DEV 单轮历史。

新增工具目前仅用于被动审计及固定历史工件，不是已准入的回放 profile，不产生 BASELINE_QUALIFIED、ADOPT 或 VERIFIED。

## 仍需完成的输入与隔离核验

1. ECS 只读元数据已将 239/239 条捕获块对应到真实文件、块、original_index 和当前 ACTIVE 构建；383/383 条种子引用均存在，且文件、父块和顺序关系匹配。捕获的引用投影仍不是完整预选择成员池；独立 recall 是问答后的诊断请求，不冒充原始 SSE 内部上下文。后续新输入必须绑定实际块文本、邻接范围、构建和 Gold 支持，不按引用顺序编造 original_index。
2. 27 条捕获文本超过旧固定 worker 的每组 max_parent_length=4000，最大 4096。该参数是单组展开设置，不是整个模型提示词的总长度上限。本轮不提高该设置来绕过事实门。
3. 已发现 4 道 DEV 的旧检索结果额外召回了 6 份 FINAL 原始资料，共 13 条引用记录。按原始文件哈希、文档 ID 和文件 ID 核对，这些资料与 DEV Gold 必要支持的交集为 0；这是可隔离的额外召回，不是重新选题的理由。新 DEV 输入需排除这些来源并保留必要支持检查；原始捕获、Gold 和题号不改动。此排除尚不等于完成来源家族独立性审定。
4. 精确字节不重合不能单独证明没有转载、翻译或版本关系。来源原始身份、家族关系及 RSI 历史使用仍需结合来源目录、快照和实验记录核对。
5. 本地来源快照可核对原始文件与引用的映射，但不是不可变索引版本证明；来源映射 VERIFIED 也不等于引用语义已验证。

FINAL 的题目、答案及证据正文不进入开发或搜索角色。现有知识库测评使用与 RSI 搜索/核查使用分别记录，不因知识库已测过这些题就自动判成 RSI 已使用，也不因旧 RSI 哈希没有命中就认定未暴露。

## ECS 与费用边界

ECS 服务和索引保持暂停。已授权的读取核对既有实验文件及精确 DEV 范围内的数据库元数据，不调用新的业务问答，不启动服务、不重建索引、不修改数据库，也不复制整库。历史候选索引的 KB 身份与本次实际请求不匹配时，不将其冒充为被测索引。

继续使用原累计 USD 5 RSI API 账本，不重置、不预留。本轮数据接收和被动输入工程尚未发起新的付费 RSI 模型请求。工程准备和测试不计自主优化收益。
