# 从正式 QA500 筛选 RSI 评测题：数量与要求

## 数量

请从现有正式 QA500 中筛选两组，共 40 道原题：

| 分组 | 数量 | 用途 |
| --- | ---: | --- |
| DEV 开发题 | 20 | RSI 开发、候选搜索、事实覆盖和压力测试 |
| FINAL 独立终测题 | 20 | 开发和总体候选冻结后的一次独立核查及配对问答 |

不需要额外准备问题改述、前向/反向 seed 变体或负控制；由 RSI 在开发题上派生并核验。单个回放包不超过 20 题是执行组织限制，不是整个项目只能使用旧的 20 题。若确实筛不齐，请交回实际数量和原因，不凑数、不擅自降低样本或统计门槛。

## 两组共同要求

- 选正式 QA500 的原题，保留原题号和原语言，避免临时改写题目或重写 Gold。
- 答案能够由知识库中的实际资料支持，保留本地 Gold 和证据依据。没有明确证据的主观题、仅凭常识的题不优先。
- 对应解析内容、文档块和索引已在 ECS。优先选能通过现有记录定位到 `kb_id`、`file_id`、`chunk_id` 或原文位置的题。
- 原文位置可以是页码、表格/行、标题、段落或已有证据文件中的定位，不要求手工重新导出文档。
- 同一原文的不同段落、不同问法、翻译或转载不能直接视为独立来源。
- 有 Gold 冲突、证据缺失或来源关系不确定的题可以另列备注，不能为了凑数量按通过处理。

## DEV 20 题的覆盖要求

以下六类每类至少选 2 道来自不同原始资料组的题。同一道题可以覆盖多类，因此总数仍为 20 道。

| 类别 | 选题时看什么 |
| --- | --- |
| 邻近证据必要性 | 只读一个起点段落不够，还需要相邻段落或表格行中的关键事实 |
| 跨块关系 | 主体、对象、关系或条件分布在不同文档块，需要合起来读 |
| 否定与条件 | “不、仅、除非、在某条件下、例外”等内容会改变答案 |
| 数值、单位与归属 | 数量、比例、金额、日期等必须与单位、对象或适用范围对应 |
| 多来源支持 | 答案确实需要两份不同原始资料；单篇文章的两个块不算多来源 |
| 引用支持 | 答案关键结论能对应到明确原文位置，能够检查错引、漏引 |

筛选时不必处理 seed、切块位置或正负控制实现；这些由 RSI 根据 ECS 的真实文档块进一步构造和核验。开发题尽量覆盖 QA500 的主要来源和题型，不必全部选最简单或最难的题。

## FINAL 20 题的隔离要求

- 目标为 20 个彼此独立的原始资料组；题内可以需要多份资料，但不同终测题之间不能共享同一来源家族。
- 与 DEV 不共用同一原文、转载、翻译或派生资料。同一原文拆成两道题分放两组不合格。
- 不用于本轮开发、候选选择或反复调试。此前知识库做过常规 QA500 测评，不自动等于 RSI 使用过；RSI 的历史使用由我们按题号、来源及实际实验记录核对。
- 不确定是否被 RSI 使用过时标为“不确定”，交由核对，不直接认定未暴露。
- 终测题和 Gold 单独保存在本地文件中；不要把终测答案贴到聊天或混入开发题文件。RSI 只会在规定的封闭核查阶段读取，不向本轮搜索角色提供反馈。

## 最少交付内容

如果现有 QA500 Gold 和证据文件已包含完整信息，只需提供：

1. DEV 的 20 个正式题号。
2. FINAL 的 20 个正式题号，放在另一份清单。
3. 本地正式 QA500 Gold、证据记录及冻结清单的路径；如题号已可直接关联，不必逐题抄写问题和答案。

如需补充，使用可选 CSV 模板记录 `qid`、类别、来源线索、证据定位及不确定事项。ECS 上的解析内容和索引由我们按标识只读核对，不要求复制整库或重建索引。
