## 本轮修改

- `backend/app/services/chat.py::ChatService._chat_stream_normal`：不再调用 `validate_grounded_answer`、逐字模板/数字匹配或 PDF 答案重写。实际可用文本证据检索成功、候选非空且正常 stop 时输出模型回答；`validation_status=NOT_RUN`，不得解释成内容已经验证。保留生成开关及空正文、截断、异常时的摘录回退。
- `backend/app/services/agent_workflow.py::_finalize_knowledge_answer`：同样停用新增内容规则；移除仅因工具轮数/引用数组一致性而拒绝自然回答的限制。保留检索成功状态、既定 Agent 质量阈值以及无证据/故障/UNKNOWN 保护，不修改评分阈值。
- `backend/app/services/grounded_generation.py::generate_grounded_candidate`：删除强制逐字照录、固定句式和附加输出格式要求；保留只根据实际资料回答、资料不足说明及引用提示。原始表头、行、脚注及说明可作为证据上下文，不作为输出模板或 Gold。
- 非流式仍为4096；普通流式不显式设置输出上限，Agent `get_chat_model` 默认 None，符合 Owner 纠正。禁用 SDK 自动重试、UNKNOWN 终止等保护保留。
- 早于该最新指令的缓存修复已在工作区：`RetrievalService.search` 绕过缺少配置/模型/索引/结果状态版本证明的旧结果缓存，每次执行真实检索。未改变算法、权重或阈值；重复 Vector/Hybrid 请求可能增加 Embedding 请求、延迟和成本，不能宣称已建设完整缓存版本体系。该修改当前仅定向模拟测试，正式运行验证尚未完成。

未提交、未推送、未切换正式服务。旧验证器文件可保留供历史复核，但普通/Agent 活动路径不调用它。评分与 Gold 未修改。正确性、忠实度及引用由测试后单独审查，不再让该内容规则阻断输出。
