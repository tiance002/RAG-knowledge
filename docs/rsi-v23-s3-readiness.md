# S3 来源、覆盖与冻结准备

工程部分新增 `source-relations/v1`，旧六文件、FIXED/EVALUATOR 和旧事实要求不变。新结构声明原始来源身份及哈希、完整区间、必要事实原子、对象/值/单位/条件/关系、AND/OR 等价支持和 review_status。评测器核对明确规则及送达/引用位置，不推断任意自然语言真假或事实清单完整性。

新 profile 已接入实际协调器、回放读取、完整家族、恢复、训练复核、预览和独立 A/A 通道的合成集成控制。多来源问题按共享来源家族的传递连通关系分簇；原始来源数、问题数、独立簇和压力变体分别记录，40 个原始来源/20 簇不会变成分母40。所有静态合格实例依旧独立回放。

`ExposureLedger` 追加来源与用途事件，区分 CONTROL/DEV/ITERATIVE_VALIDATION/FINAL_HOLDOUT，记录转载、节选、派生及版本关系；UNKNOWN 有明确标记，不能通过新哈希扩大独立簇。保守导入中所有未知家族合并处理，不宣称101份独立知识来源。快照必须与实时账本一致，已见或暴露不明不能进入终测。

研究策略 `research-source-family/v1` 可明确接受已知家族、绑定审定的 AI_REVIEWED；生产策略仍严格，并标记独立高风险复核未完成。不将 AI 自检写成人审，也不为了启动研究临时制造人工审阅记录。

实际只读清点复用了冻结 DEV：20 来源/20题，旧事实27/27区间、成员185/185区间核对，来源哈希无错。19份历史决策含380次问题使用，它们不是380份独立来源样本。新增六类 profile 的已审定原子和配对负控制为0，六类均 **BLOCKED_DATA**，不能用旧 seed 条款冒充。

历史 metadata 导入登记101个来源身份、1757次 manifest 出现和18个已消耗旧核查来源哈希；其中包含合成控制资料，不能作为真实语料规模。两份旧受限 manifest 不可读，记录历史不完整和 UNKNOWN，未改变权限或读取其 Gold。初版导入的权限错误与家族重包装拒绝保留；新版导入采用统一未知家族，未改旧账本。

真实基线资格未运行，初始 ACTIVE 经验允许为空，但本次没有为真实搜索伪造冻结快照。模型公开价格核对参考官方 [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) 与 [Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) 页面；实际配置的模型元数据 GET 遭遇网络错误，身份可用性为 UNKNOWN。没有据此调用付费生成接口。

结论：**S3 真实准入 BLOCKED**。须补原文可定位的新 profile 六类事实及配对控制、来源家族/暴露审定、实际模型身份，再真实执行 A/A 并冻结基线/经验/分析计划。不是通过放宽事实门、把旧 JSON 补字段或重新包装旧核查就能解除。
