## 变更与取舍

- `backend/app/services/agent_workflow.py`：按服务端范围和请求设置调用工具；显式资料问题优先进入知识库路径；知识库最终输出取自实际可回读的引用原文，不输出模型未核查的事实；Agent 原始 Thinking 不再透传用户界面。多轮中保留已有证据，对异常或不足作说明。Agent 空范围不再自动扩展成所有知识库。中英文意图识别仍是规则和原模型结合，复杂否定、多轮指代及其他语言不能保证不误判。
- `backend/app/services/chat.py`、`api/chat.py`：正式 SSE 抑制未经保护的 Agent 输出；普通知识库问答输出来源摘录并保留引用和状态；无知识库的普通聊天维持模型流。流中途失败或 `finish_reason=length` 返回明确 error，不发送误导性的成功 done。检索故障文案区分检索与模型错误。
- `backend/app/services/retrieval.py`、`backend/app/tools/retrieval_tool.py`：检索状态传到工具并区分 NO_RESULTS、RETRIEVAL_ERROR、UNKNOWN；已有证据遇到重排异常时保留并标记不确定；返回真实 chunk、文件、页码、内容类型。无法确认的缓存结果为 UNKNOWN。无结果与故障并不混为一谈。
- `backend/app/services/llm.py`、`embedding.py`、`rerank.py`：模型、Embedding 和 Rerank 的发送前创建 local_request_id，记录阶段、模型、尝试及可获取的安全 provider ID；超时或传输中断 UNKNOWN 向上终止，禁止隐式 SDK/业务重试。已知连接前失败、已知 HTTP 失败和 UNKNOWN 分开记录；不记录密钥或错误正文。
- 图片占位符和图片描述不作为已核实的文字原文，提示需要进一步核验；未切换 PDF 解析器。**取舍：知识库问答当前返回原文摘录，不再进行综合生成或自动图片描述。** 摘录可回读不等于足以回答、事实真实或完整；回答可读性及多格式能力退化需后续针对性解决。
- `observability.py` 的 `search_mode` 白名单仅允许 vector/fulltext/hybrid 明文，用于核对实际配置；密钥及任意内容仍脱敏。P0.2 既有 event_id 机制保留。
