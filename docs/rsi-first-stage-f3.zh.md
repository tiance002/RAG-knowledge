# RSI 第一阶段 F3 历史档案与多父代选择

阶段从 F2 `e40cf45d` 起步。F3 复用既有独立核查、Query Registry、训练采纳、冻结 Launch 和历史制品，目标排名和执行资格分别记录。

## 接线范围

原 `autonomous.run` 只保存最近训练采纳的候选及对应普通回放路径。显式启用 F3 时，宿主从冻结 launch plan 读取父代选择模式、种子和当前 Objective，并对照本轮冻结策略。每轮先从可信根与本次运行内已通过训练采纳的后代中选择一个父代，再进入原有 Diagnosis/P1/P2/P3 工作流。每个候选使用自己的 A/B 回放中的 B 臂作为下一轮 frame。

同一冻结运行的早先训练通过候选，可以沿现有 `exploration_training` 启动门重验。该门要求训练回执、协调轮身份、祖先链回到冻结根，以及计划显式允许训练探索。F3 不将这类候选标记为独立 VERIFIED。若候选无资格或其证据冲突，继续保留既有候选制品和原因。

| 模式 | 设计 |
| --- | --- |
| `latest` | 当前目标下最新进入且仍具备资格的候选。 |
| `all_eligible` | 轮换所有可执行候选，优先选取使用次数最少者。 |
| `pareto` | 在同一可比范围考虑已测维度。跨范围保留，不按数值混排。 |
| `seeded_multi_branch` | 使用冻结种子，让已准入的分支可复现地获得机会。 |

候选历史用途与资格分开。`TRADEOFF`、退化、未完整测量及未采纳项目原样保留，不能靠排名进入父代池。父代选择对绝对上下文字符数有明确测量口径，相对各自父代的变短、变长题数不作为跨父代排名的数值。最终问答、真实模型 Token、TTFT 等保持以往证据边界。

每轮的 `parent-selection.json` 在构造角色前落盘，记录冻结模式、目标、Launch 与根资格回执、参与父代及排除原因、被选 B 臂的证据摘要。写入绑定到本轮基线与状态。重验识别候选版本、回放改动、路径越界和隔离状态。没有可选者会先留下终止诊断，再停止该次搜索。已归档的候选历史不回写。`latest` 之外的模式为宿主显式 opt-in，旧计划继续使用既有路径。

| --- | --- |
| `latest` | 最新的合格后代 6 次。 |
