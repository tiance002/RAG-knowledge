超长行先受本次解析 chunk_size 限制；父子模式继续按父子字符预算切分。定位为工作表原始行列，文本切片偏移仅为行文本内偏移，不伪造 Excel 字节位置或页码。API、持久队列、旧解析入口和 WeKnora 风格前端解析弹窗传递相同开关。
